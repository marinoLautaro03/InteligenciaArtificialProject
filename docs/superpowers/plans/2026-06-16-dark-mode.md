# Dark Mode Toggle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a sun/moon toggle to the sidebar that switches between light and dark themes, persisting the choice in `localStorage` and initialising from the OS preference.

**Architecture:** All colors are already driven by CSS custom properties in `index.css`. Adding a `[data-theme="dark"]` block that overrides those tokens — set on `document.documentElement` — propagates the theme globally without touching any page component. Theme state lives in `ShellContent` (already the top-level authenticated component); a `useEffect` syncs state → DOM and `localStorage` on every change.

**Tech Stack:** React 19, TypeScript, CSS custom properties (`oklch`), `localStorage`, `window.matchMedia`

**Spec:** `docs/superpowers/specs/2026-06-16-dark-mode-design.md`

### Task 1: CSS dark-mode tokens

**Files:**
- Modify: `frontend/src/index.css`

- [ ] **Step 1: Add the dark token block**

Open `frontend/src/index.css`. After the closing `}` of the `:root` block (line 41), insert:

```css
[data-theme="dark"] {
  color-scheme: dark;
  --bg: oklch(0.16 0.005 80);
  --surface: oklch(0.20 0.005 80);
  --surface-2: oklch(0.23 0.005 80);
  --fg: oklch(0.96 0.005 85);
  --fg-muted: oklch(0.70 0.008 80);
  --fg-soft: oklch(0.55 0.008 80);
  --border: oklch(0.28 0.006 80);
  --border-strong: oklch(0.36 0.008 80);
  --accent-soft: oklch(0.30 0.06 50);
}
```

`color-scheme: dark` tells the browser to render native controls (scrollbars, inputs) in dark style. All other tokens flow through automatically.

### Task 3: Theme state and DOM sync in AppShell

**Files:**
- Modify: `frontend/src/components/AppShell.tsx`

- [ ] **Step 1: Import the new icons**

In `frontend/src/components/AppShell.tsx`, find the existing import block at the top. Add `Sun` and `Moon` to the Icons import:

```tsx
import { Sun, Moon } from './Icons';
```

- [ ] **Step 2: Add theme state inside `ShellContent`**

In `ShellContent`, after the existing `const [sidebarOpen, setSidebarOpen] = useState(false);` line, add:

```tsx
const [dark, setDark] = useState<boolean>(() => {
  const saved = localStorage.getItem('theme');
  if (saved) return saved === 'dark';
  return window.matchMedia('(prefers-color-scheme: dark)').matches;
});
```

The lazy initialiser runs once on mount. It reads `localStorage` first; if nothing is saved it falls back to the OS preference via `matchMedia`.

- [ ] **Step 3: Add the sync effect**

After the existing `useEffect` (the one that closes the sidebar on route change), add:

```tsx
useEffect(() => {
  document.documentElement.setAttribute('data-theme', dark ? 'dark' : 'light');
  localStorage.setItem('theme', dark ? 'dark' : 'light');
}, [dark]);
```

This runs whenever `dark` changes — including the first render — so the DOM attribute is always in sync.

### Task 4: Toggle button in the sidebar

**Files:**
- Modify: `frontend/src/components/AppShell.tsx`

- [ ] **Step 1: Add the toggle button to the sidebar JSX**

In the sidebar JSX inside `ShellContent`, find the `<div className="spacer" />` element. Insert the toggle button immediately **after** the spacer and **before** the `<div className="user-card">`:

```tsx
<div className="spacer" />

<button
  className="btn btn-ghost btn-icon theme-toggle"
  onClick={() => setDark((d) => !d)}
  title={dark ? 'Cambiar a modo claro' : 'Cambiar a modo oscuro'}
>
  {dark ? <Sun size={15} /> : <Moon size={15} />}
</button>

<div className="user-card">
```

Convention: shows the icon of the *destination* state — Sun = "go to light", Moon = "go to dark". This matches the standard toggle pattern (VS Code, GitHub, etc.).
